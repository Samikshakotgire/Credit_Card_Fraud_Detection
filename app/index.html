End-to-End MLOps Pipeline Flow

1. Stratified Ingestion & Feature Engineering

Data is scaled and balanced. Transaction `Amount` is normal-scaled via `log1p(Amount)`, and `Hour` is extracted to capture circadian patterns of fraudulent charge bursts.

2. Leakage-Free Over-sampling (SMOTE)

Using imbalanced-learn pipelines, SMOTE generates synthetic fraud vectors only inside CV loops to guarantee that no test set data leaks into the model training bounds.

3. XGBoost Model & Optuna Bayesian HPO

A gradient boosted trees architecture is tuned across 30 Optuna trials to directly maximize the Precision-Recall Area Under the Curve (PR-AUC), bypassing deceitful standard accuracy metrics.

4. Production Deployment Packaging

The serialization yields `fraud_model.pkl`. FastAPI loads this binary once at server startup and containerizes it with a highly optimized Python-slim Dockerfile ready for horizontal cloud orchestration.
